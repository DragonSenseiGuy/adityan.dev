ChatGPT Atlas
=============

ChatGPT Atlas is newest AI Browser by OpenAI. This browser is a rival to Perplexity's [Comet](https://www.perplexity.ai/comet/) and Browser Company's [Dia](https://www.diabrowser.com/).

This Browser unlike Dia can do things for you by having control over your mouse, even Comet is able to do this. Atlas shows OpenAI's investment into other sectors of AI. The Browser is also macOS only. I own a mac so I was able to test this.

Security
--------

Atlas has some of the best security I have seen, Brave has pointed out [vulnerabilities in Comet](https://brave.com/blog/comet-prompt-injection/) and [unseeable prompt injections](https://brave.com/blog/unseeable-prompt-injections/)

Chromium
--------

Atlas is based on Chromium, which holds over 70% of the market share, notably Chrome.

Web Confinement
---------------

The default homepage for Atlas looks like the [chatgpt.com](https;//chatgpt.com) website, there are pros and cons to this. The biggest con is that the interface confines the web, If you search for something like "Taylor Swift showgirl' you get "something closer to a last-minute book report written by a kid who had mostly plagiarized Wikipedia. The response mentioned some basic biographical information and had a few photos. Now we know that AI tools are prone to this kind of confabulation, but this is new, because it felt like I was in a web browser, typing into a search box on the Internet. And here's what was most notable: **there was no link to her website**." ([Source](https://www.anildash.com/2025/10/22/atlas-anti-web-browser/)) .
