So a while ago I disabled newsletters in this blog(forked from [simonw/simonwillisonblog](https://github.com/simonw/simonwillisonblog/tree/main). This is because I did not want to set them up yet, I just wanted the blog up and running.

Finally Adding Newsletters
--------------------------

After giving it much thought I decided to just go for it, so I began looking. I came across the one Simon Willison was using, [Substack](https://substack.com). It's feature for bloggers was free, unless you had a paid blog in which Stripe and Substack would take a cut.

Setup
-----

The setup was easy

1.  Sign up
2.  Add a blog
3.  Copy my blog
4.  Paste
5.  Publish I won't go into the details here but, that's all it took. I also had to add an `iframe` embed into my website.

Final Thoughts
--------------

The newsletter is working great! I have no issues so far and I am amazed that this is all for free, Substack probably gets enough money from paying users to allow this very generous free tier. If you guys want to sign up to my newsletter [here](https://dragonsenseiguy.substack.com)
