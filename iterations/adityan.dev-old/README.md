# Aditya's Website

My personal website and blog, built with Hugo using a customized version of the Coder theme.

## About

This is where I share my projects, write about things I'm learning, and generally have a place on the internet to call my own. The design is inspired by [aconlin.com](https://aconlin.com/).

## Running Locally

Make sure you have Hugo installed, then:

```bash
hugo server
```

The site will be available at `http://localhost:1313`.

## Building

```bash
hugo
```

The static files will be generated in the `public/` directory.

## Structure

- `content/` - Blog posts, projects, and other pages
- `layouts/` - Custom layout overrides
- `static/` - CSS, images, and other static assets
- `themes/coder/` - The base Hugo theme (as a submodule)
